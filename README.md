## 🎙️ Voice Recording and Playback System

This project is a simple **Python-based voice recording system** that records audio through a microphone, saves it as a `.wav` file, and plays the recorded audio.

### 🛠️ Technologies Used

* **Python**
* **SoundDevice** – for recording and playing audio
* **SciPy** – for saving the recording as a WAV file

### ⚙️ How It Works

1. Sets the recording frequency to **44.1 kHz**.
2. Records audio for **5 seconds** using the microphone.
3. Saves the recording as `output.wav`.
4. Plays the recorded audio through the speakers.

### 🎯 Objective

The main objective is to understand **basic audio recording, file handling, and audio playback using Python**.

### 📚 Learning Outcome

This project helped me learn how to use Python libraries, work with audio input/output, and create and save audio files programmatically.
